# الخطيب المترجم — Al-Khateeb Translator

موقع Django لترجمة الخطبة **نصيًا** إلى لغات متعددة، بدون إخراج صوتي.

## الترجمة المجانية
المشروع يستخدم **Argos Translate** كنموذج ترجمة مفتوح المصدر يعمل محليًا على الخادم، بدل OpenAI أو Google Cloud. لا يحتاج مفتاح API أو بطاقة دفع. Argos يدعم نماذج ترجمة محلية، ونموذج M2M100 متعدد اللغات يغطي عددًا كبيرًا من اللغات.

> ملاحظة: النموذج المجاني الحالي لا يغطي كل اللغات الـ24 الموجودة في واجهة الموقع. اللغات غير المدعومة ستظهر للمستخدم برسالة واضحة بدل إظهار ترجمة خاطئة.

## التشغيل المحلي
Windows:
```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
ثم افتح http://127.0.0.1:8000

أثناء عملية البناء، يتم تنزيل نموذج Argos متعدد اللغات (حوالي 437MB) وتثبيته حتى لا ينتظر أول مستخدم تنزيل النموذج.

## النشر على Render المجاني
1. ارفع المشروع إلى GitHub.
2. في Render: New → Blueprint.
3. اختر مستودع GitHub.
4. Render يقرأ `render.yaml`.
5. لا توجد `OPENAI_API_KEY` ولا مفاتيح ترجمة مدفوعة.
6. افتح رابط `onrender.com` بعد نجاح البناء.

## الحديث
صفحة التنبيه تعرض حديث الجمعة بالعربية، وعند اختيار لغة أخرى يحاول الموقع عرض **ترجمة آلية للحديث** بنفس نموذج الترجمة. تبقى العربية هي النص الأصلي، لأن الحديث نص ديني ويجب عدم التعامل مع الترجمة الآلية على أنها نص حديث أصلي.

## ملاحظات مهمة
- الموقع يستخدم SpeechRecognition في Chrome/Edge للالتقاط النصي المباشر من كلام الخطيب؛ لا يوجد Text-to-Speech ولا صوت صادر من الموقع.
- بعد ظهور كل مقطع عربي، يرسله الموقع إلى Django لترجمته إلى اللغة المختارة.
- العربية تعرض النص العربي مباشرة، وهي مناسبة للصم وضعاف السمع.
- Render Free مناسب للتجربة وليس للاستخدام الإنتاجي؛ النموذج كبير نسبيًا وقد تكون أول ترجمة بطيئة.
